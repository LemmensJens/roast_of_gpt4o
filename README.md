# The Roast of GPT4o: Experiments in Generating, Detecting and Evaluating Celebrity Roast Comedy

This repository contains the data, prompts, and code used for the following paper:

Jens Lemmens, Jérémy Genette, Tony Veale, and Walter Daelemans. 2026. The Roast of GPT4o: Experiments in Generating, Detecting and Evaluating Celebrity Roast Comedy. The Second Workshop on Computational Humor (CHum), pp.1-7. Online (co-located at ACL 2026). Association for Computational Linguistics (ACL).

## Code
This folder contains the R script used to compute the statistics presented in the paper.

The code that was used to scrape the data* can be found here: https://github.com/LemmensJens/scrape_ytb, which is based on https://github.com/imomayiz/youtube_scraper.git

## Data
This directory contains the anonymized responses. A link to the actual survey can be found here: https://docs.google.com/forms/d/e/1FAIpQLSdDcXP6A_DB02HtgloOPJ6hFQejioSYIHq11dP5nGP2J2kMkg/viewform?usp=dialog


## Prompts
Contains the prompts used to generate the AI roasts, and the summaries of the human roasts.

*Due to copyright reasons, the actual data is not shared in this repository, but the code used to scrape the data is provided.
